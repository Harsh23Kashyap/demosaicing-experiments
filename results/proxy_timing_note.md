# Exploratory cost measurement, 28 Sep 2026

The revised `analysis/external_proxy_set14.py` on the same 12 RGB Set14 files times both the original bilinear reconstruction + `descriptors` (all nine descriptors) and a lean bilinear reconstruction + `rgb2hsv(...)[...,1].mean()` (the one saturation feature actually used). Both follow the same pipeline mosaic and sRGB conversion; per-image saturation was asserted equal to tolerance 1e-12, so model predictions did not change. Median 171.943 ms (all descriptors), 82.771 ms (lean). These passes are sequential rather than randomized, share a single warmed process, and depend on image dimensions, machine and library state. This is a component feasibility check, not a properly paired method-versus-policy latency benchmark. On the newer machine, do not compare these medians as absolute numbers against the earlier 38-image table. Full fast-method costs, optimized re-use and end-to-end policy latency are not measured together. The performance result remains negative: 7/12 versus constant Malvar 7/12.
